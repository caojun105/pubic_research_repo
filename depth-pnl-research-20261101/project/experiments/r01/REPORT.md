# R01：盘口算法对照实验

实验日期：2026-11-02。状态：已运行、核账通过；探索性结果，尚无未见数据验证。金额均为 USDT，手续费为假设，不代表账户实际费率。

## 本轮问题与协议

同一小时的公开研究信号，能否比原策略提取更多可执行利润？观察区间为北京时间2026-11-01 11:12:26.715—12:12:26.715。前40分钟选择参数，后20分钟固定参数评估。已知这小时的原策略结果，故不能称为全新样本外检验。

运行前固定 [plan.json](plan.json)：7个新增版本、每版本3个入场阈值，共21个候选。各自选择训练零费/100ms下利润最高且至少5笔完整交易的候选；没有正收益合格候选则保持空仓。7个新版本间的训练冠军是 **obi6**，不是看测试段后换出的算法。原策略沿用之前32候选选出的参数，作历史参照。

所有模型使用0.01 BTC、现货做多/空仓、500ms入场持续确认、300ms转弱退出、30秒最长持仓、相同延迟后逐档VWAP、同样的边界清仓。参数不在敏感性场景重选。测试段重新开始空仓和信号确认计时；滚动特征允许使用当时已经到达的历史数据。

### 本轮发现

1. **简单 OBI 是训练选出的下一阶段候选。** 入场阈值0.4，退出阈值0；OBI=(B−A)/(B+A)，因此入场等价于买量至少为卖量约2.333倍。它没有原策略的买一量最低门槛。测试比原策略多盈利约0.0395 USDT，属于小幅改进，不能称为稳定超额收益。
2. **动态信息并未自动改善结果。** OFI1有43笔交易，1bps后亏损6.4169 USDT；短持仓使其本小时回撤小，但不能仅凭回撤小认定更优。OFI5和组合版本也没有超过简单深度版本。当前固定窗口/归一化/持仓规则下的失败不代表OFI在所有场景无效。
3. **弱价格动量对照帮助定位信息来源。** momentum1零费只有0.0311 USDT；静态深度版本更强，支持继续研究盘口特征，但还不能做因果归因。
4. **盈利仍集中。** OBI最好3笔合计0.4895 USDT，占净利润约79.5%；去掉它们只剩0.1266。四个5分钟区间按平仓时间归属的利润为+0.2889、−0.1001、+0.2108、+0.2165；这些不是四个独立清仓回测，也不是独立市场环境。
5. **规模并非线性放大。** OBI同规则0.01／0.1／1 BTC的零费利润约0.6161／5.6046／24.1501。更大订单吃到更差报价。这只是可见历史深度压力测试，没有订单自身市场冲击和竞速模型，不能据此确定实盘容量。
6. 所有版本在每边1bps时均亏损。零费条件下可继续验证；有费用时，应先研究减少周转和提高单次预期优势，而不是追求更多交易。

## 特征定义和公开研究依据

| 特征 | 实现 | 来源和边界 |
|---|---|---|
| qi | (买一量−卖一量)/(买一量+卖一量) | [Gould & Bonart](https://arxiv.org/abs/1512.03492)研究美股下一次中间价变动；此处移植信号并用阈值策略，没有复刻其逻辑回归，也不迁移论文准确率 |
| book pressure | (卖一价×买一量+买一价×卖一量)/总量 | [Headlands](https://blog.headlandstech.com/2017/08/03/quantitative-trading-summary/)的教学信号；pressure−mid=QI×spread/2，因此不重复作为独立策略，也不是校准后的复杂microprice模型 |
| obi6 | 距中间价每侧6 USDT内总量的不平衡 | 延续原项目的价格分档；这是很窄的价格范围，不是订单簿全部深度，也不是“前六个报价档位” |
| weighted6 | 6个1 USDT价格分档，权重1/(j+1) | 近价权重为本实验假设，不声称论文已证明这个权重最优 |
| ofi1/ofi5 | 累加最优报价/数量变化的净流量，除以窗口内平均买一卖一总量 | [Cont–Kukanov–Stoikov](https://arxiv.org/abs/1011.6402)给出事件OFI；原文主要是同期价格冲击证据，此处单独测试未来预测。滚动窗和归一化是本地实现选择 |
| combo | min(obi6/0.2,ofi1/0.25)，大于入场阈值才入场 | 自定义两信号同时确认的消融实验，不是已发表盈利算法 |
| momentum1 | 过去1秒中间价收益bps | 非盘口量的价格对照，方向固定为正，不根据测试翻转方向 |

OFI事件值：买价不降时加当前买量、买价不升时减前买量；卖价不升时减当前卖量、卖价不降时加前卖量。我们的输入约100ms合并更新，不能恢复其间每一笔挂单/撤单；因此称为**观测级OFI代理**。滚动窗只使用已到达更新，等待完整1／5秒预热；断流和会话切换清空历史。当前尚未加入逐笔主动成交特征。

## 预测和交易分开核查

[prediction.csv](results/prediction.csv)提供未来1／5／30秒中间价收益的Pearson相关与高低信号分组差。每个期限按该期限步长采样，收益区间不重叠；高低组阈值只由训练分位数确定。标签严格留在各自时间段内，价格使用截至时点最新已知盘口。

例如5秒测试有239个收益区间：OBI相关约0.273，QI约0.277，OFI1约0.134，纯价格动量约0.013。它们是本小时的描述统计，不是盈利概率。30秒仅39个区间；即使相关系数更高也不能作为可靠证据。不同特征高度相关，仍有时间依赖、重复比较和历史探索偏差，没有经校正的显著性检验。

## 下一轮的冻结规则

- 保留OBI入场0.4、退出0、原始30秒持仓规则作为新数据验证候选，不以当前测试结果反复微调。
- 获取未参与本轮探索的多日L2快照、增量和逐笔成交，覆盖上涨、下跌、横盘及活跃/安静时段；记录每段真实接收时间和断流。
- 在新数据比较原策略、冻结OBI、OFI和不交易/买入持有，先看净收益分布与日际稳定性，再考虑扩大参数搜索。
- 后续独立实验再加入主动成交不平衡、持续性/撤单特征及成本门槛；不能用本小时的相同测试段给新模型作“独立验证”。
