# 黄金跨交易所刷量成本回测（中文）

## 口径与关键限制

**Fact**：本报告由 `backtest_xau.py` 实际运行生成。每条快照各执行一次假设买卖，买价取 ask、卖价取 bid，字符串显式转 float；同一行四市场视作同批采样，不做未来插值。按 ts 稳定排序，重复 ts 保留最后一行；仅使用四市场都有效的共同样本，确保横向比较一致。所有统计为等快照权重，std 为样本标准差，分位数为 pandas 线性插值。

金额均按每腿一个相同黄金价格单位归一化，假定美元与 USDT 等值、各产品价格单位可比。未经合约乘数核验，不代表每所一张合约，也不保证可以按一单位实际成交。正磨损为成本，负磨损仅表示报价优势。

**重要**：不同交易所的一买一卖并不平掉各自仓位：它形成一多一空。不断重复同一方向会累积库存。不同 Var 产品也不能彼此直接平仓。故下文两腿负成本不是已经实现的套利收益；完整往返须再反向交易两腿。纯同产品的一买一卖才能在该产品上直接闭合仓位。

计算：毛磨损 = ask买 − bid卖；净磨损 = 毛磨损 + f×(ask买 + bid卖)。f 为两边相同的单边 taker 费率。每百万成本 = 净磨损之和 / 相应成交名义之和 × 1,000,000；买卖均计成交量。Var 全产品分母计永续及 swap，Var 永续分母仅计永续；积分是否认可 swap 不在数据中。累计数为每个有效快照一次假设成交的机械累计，不代表可实现容量。

资金费、持仓融资、滑点、冲击、网络延迟、合约基差结算及 USDT 汇率均未计入；缺少实际持仓及完整资金费账单，不能从预测字段严谨推算已实现资金费。统计不是实盘成交回放，无训练、无选参、无前视择优。

## 判断与推荐（Inference）

两腿表最小值可用于识别建仓报价优势，但不能作为无限重复刷量的利润预测。对于只追求 Var 永续成交量、要求库存反复归零的目标，同快照四腿对冲额外承担对冲所 spread 和手续费，不能靠静态跨所报价差突破纯 Var 的成本。需要持仓并等待基差变化的策略属于额外风险策略，本次短窗口不足以证明其长期有效。

如果 swap 也计目标积分，可优先比较纯 swap 的闭合往返成本；其积分规则、合约规模与实盘成交能力需要另行核实。最大可实现交易量无法由这些顶层报价确定：Var 缺深度，HL 张数口径未核验，重复采样不等于流动性刷新。建议把报告作为成本筛选而非实际收益承诺。
